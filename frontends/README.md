# frontends/

Per-OS input-method plugins. Each is a thin client of `xlit-core` (linked
directly for now, or via `xlit-daemon` later).

- `linux-ibus/`   — IBus engine (GNOME + most distros). First target, milestone M4.
- `linux-fcitx5/` — Fcitx5 addon (KDE + power users). Milestone M5.
- `windows-tsf/`  — TSF Text Input Processor. Milestone M6.

None implemented yet.
